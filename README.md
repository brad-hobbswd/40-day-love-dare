# 40 Day Love Dare with Your Spouse

An independent Christian marriage devotional and coaching website by Coach Brad Hobbs.

**Live website:** https://brad-hobbswd.github.io/40-day-love-dare/

## Website pages

- `index.html`: Home page
- `about.html`: About Coach Brad
- `devotions.html`: Directory of the 40 daily devotions
- `journey.html`: Guided overview of the 40 day journey
- `day-01.html` through `day-40.html`: Individual daily devotion pages
- `privacy.html`: Privacy policy
- `terms.html`: Terms of use
- `copyright.html`: Copyright and attribution
- `styles.css`: Shared responsive styling
- `sitemap.xml`: Search engine sitemap
- `robots.txt`: Search engine crawl guidance

## Daily page format

Each daily page includes a Scripture reference, original coaching reflection, practical action, personal reflection, prayer, and previous or next day navigation.

## Editing the website

This is a static HTML and CSS website hosted with GitHub Pages. Edit the relevant HTML file and commit the changes to the repository's published branch. The site does not currently require a build step or a JavaScript framework.

## Design notes

The site uses a centered, confined layout with clear outer margins and a romantic palette of burgundy, blush, champagne, sage, and gold. Shared styles are maintained in `styles.css`.
